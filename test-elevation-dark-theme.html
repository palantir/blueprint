Blueprint Card Elevation - Dark Theme Fix

This page demonstrates the fix for GitHub Issue #7569: Dynamic box-shadow CSS attribute under light/dark theme for bp6-elevation-# classes.

What was fixed: The elevation classes now automatically apply dark theme shadows when the system prefers dark color scheme using @media (prefers-color-scheme: dark).

How to test:

  • The cards below show elevation levels 0-4 in both light and dark backgrounds
  • In light mode, shadows should be subtle and dark
  • In dark mode (or when your system is set to dark theme), shadows should be more prominent with lighter borders
  • You can toggle your system's dark mode to see the automatic theme switching

Technical Details

Changes made to packages/core/src/components/card/_card.scss:

  1. Added @media (prefers-color-scheme: dark) support to the base .bp6-card class
  2. Added @media (prefers-color-scheme: dark) support to all elevation classes (.bp6-elevation-0 through .bp6-elevation-4)
  3. Added @media (prefers-color-scheme: dark) support to interactive card states (hover, active, selected)

The fix maintains backward compatibility with the existing .bp6-dark class-based theming while adding automatic theme switching based on system preferences.
