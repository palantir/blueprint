@# Labs

<div>
    <h4>Under construction</h4>

The **[@blueprintjs/labs](https://www.npmjs.com/package/@blueprintjs/labs)** NPM package contains **unstable React components under active development by team members**.
It is an incubator and staging area for components as we refine the API design; as such, every minor version should be considered breaking. This has started at version 1.0.0 to signal resurrection of the package after a hiatus.

The goal for the labs package is to eventually graduate components into the core package. The criteria to evaluate promotion into core will be as follows:

- It should have a stable and well-designed API
- It should be well-tested
- It should have documentation and examples
- It should match the code quality of the core components

</div>
